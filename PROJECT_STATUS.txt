9. IMPORTANT CONCEPTS UNDERSTOOD
============================================================

X:
Input features.

y:
Target variable.

Supervised Learning:
Training data contains known input-output examples.

Regression:
Target is a continuous numerical value.

Multiple Linear Regression:
Uses multiple input variables to predict one numerical
continuous target.

Encoding:
Converts categorical text values into numerical values.

drop_first=True:
Uses one category as the reference category and avoids
redundant dummy variables.

Residual:
Actual value - Predicted value.

OLS:
Ordinary Least Squares.

OLS finds coefficients that minimize the sum of squared
residuals.

Training:
model.fit(X_train, y_train)

Prediction:
model.predict(X_test)
